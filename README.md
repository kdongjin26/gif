# 이미지 도구 (Image Tools)

브라우저 단일 파일로 동작하는 개인용 이미지 편집 도구 모음. 인터넷 연결 필요 (일부 라이브러리 CDN 로드).

## 파일 구조

```
index.html   # 탭 셸 (진입점) - iframe으로 crop/anim 전환
crop.html    # 자르기 도구
anim.html    # 합치기 도구 (이미지 → APNG/WebP 애니메이션)
```

3개 파일 모두 **같은 폴더**에 있어야 작동. `index.html` 더블클릭해서 실행 (Chrome/Edge 권장).

## 진입점: `index.html`

- 상단 탭: `[✂️ 자르기]` `[🎞 합치기]`
- 기본 모드: 자르기
- iframe으로 두 도구를 각각 로드해 상태 격리

---

## 1. 자르기 (`crop.html`)

원본 해상도 유지하며 선택 영역만 PNG로 저장.

### 기능
- 다중 이미지 로드 (파일 선택기 + 드래그 앤 드롭)
- 좌측 목록에서 이미지 전환/삭제
- 8개 핸들(코너 4 + 변 4)로 영역 선택/리사이즈
- 선택 영역 내부 드래그 → 이동, 외부 드래그 → 패닝
- 마우스 휠 → 커서 위치 기준 확대/축소
- 회전 90° 단위 (CW/CCW), 좌우/상하 뒤집기
- 삼분할 격자 오버레이
- 전체 선택 버튼
- 저장: 선택 영역을 **PNG**로 (무손실), 파일명 `<원본명>_cut.png`
- 저장 후 창 유지 → 여러 영역 이어서 작업 가능

### 기술 노트
- 회전/뒤집기는 offscreen canvas(`source`)를 재생성하고 선택 영역 좌표도 함께 변환
- 저장은 `canvas.toBlob('image/png')` (무손실)

## 2. 합치기 (`anim.html`)

여러 이미지를 한 애니메이션 파일(APNG/WebP)로 변환.

### 의존 라이브러리 (CDN)
- `pako@2.1.0` — deflate
- `upng-js@2.1.0` — APNG 인코더

### 기능

#### 이미지 관리
- 다중 로드 (버튼 + 드래그 앤 드롭)
- **자동 정렬** — 로드 직후 파일명 오름차순 (커스텀 `naturalCompare`)
  - `aaa.png < aaa_a.png` 등 ASCII 구두점 순서 정확히 반영
  - `img2.png < img10.png` 숫자 자연 정렬 유지
- 드래그로 프레임 순서 변경
- 개별 교체/삭제 버튼
- 각 프레임 좌측 **체크박스** (기본 체크) — 출력/미리보기/일괄자르기에서 제외 가능
- `모두 선택` / `모두 해제` 버튼
- `✕ 체크 삭제` — 체크된 프레임만 목록에서 제거
- `✕ 해제 삭제` — 체크 해제된 프레임만 제거 (체크된 것만 남김)
- `전체 삭제` 버튼 (툴바 좌측)

#### 프레임 시간
- 개별 ms 입력 (프레임마다 다른 지연 가능)
- 전체 일괄 적용 입력창 + 버튼
- **기본값 400ms**

#### 반복
- 드롭다운: 무한 (기본) / 1·2·3·5·10회 / 직접 입력

#### 크기 처리
- `최대 크기 맞춤 (여백)` (기본) / `첫 프레임 크기`
- 배경색 선택 or `투명` 체크박스

#### 출력 포맷
- **WebP (기본)** — 고품질 + 작은 용량 (`canvas.toBlob('image/webp', 1.0)` + VP8/ALPH 추출 → RIFF 컨테이너 조립)
- **APNG** — 무손실 풀컬러 (UPNG.js, cnum=0)
- 저장 기본명: `<마지막_선택된_프레임명>_webp.webp` 또는 `_apng.png`
- "다른 이름으로 저장" 버튼 별도

#### 미리보기
- 재생/정지 (스페이스바 토글)
- 체크된 프레임만 순환

#### 일괄 자르기 (핵심 기능)
툴바의 `일괄 자르기` 버튼 → 모달 오픈.

**비율 드롭다운** — `자유 / 1:1 / 2:3 / 3:2 / 9:16 / 16:9 / 3:4 / 4:3 / 4:5 / 5:4`
- **기본값: 9:16 (세로)**
- 기본 상태에서도 이 비율로 크롭 적용됨 (원본 그대로 쓰려면 `자유` 선택)

**비율 고정 모드 (예: 9:16):**
- 각 프레임마다 해당 비율의 최대 박스를 중앙에 자동 배치
- **박스 내부 드래그** = 중앙 위치 이동 (모든 프레임 동기)
- **4개 꼭지점 핸들 드래그** = 비율 유지한 채 스케일 조정
- 프레임 해상도가 달라도 각자 정확히 지정 비율로 크롭됨
- 출력 시 공통 캔버스에 비율 유지 스케일 → 모든 프레임 출력 크기 동일

**자유 모드:**
- 상/하 = 스트립 전체 가로선 2개 (모든 이미지 같은 % 적용)
- 좌/우 = 각 이미지별 세로선 (모든 프레임에 같은 % 위치 표시)
- 비율 기반이라 해상도가 달라도 비율은 동일하게 잘림

모달 버튼: `초기화 / 취소 / 적용`

### 단축키
- `Ctrl+O` — 불러오기
- `Ctrl+S` — 저장
- `Space` — 미리보기 재생/정지
- `Delete` — 선택된 프레임 삭제

### 기술 노트
- **WebP 인코딩:** 프레임별 `canvas.toBlob('image/webp', 1.0)` → VP8/VP8L/ALPH 청크 추출 → 수동으로 RIFF `WEBP` 컨테이너 조립 (`VP8X` + `ANIM` + `ANMF` per frame)
- **APNG 인코딩:** UPNG.js로 전체 인코딩 후 `acTL` 청크의 `num_plays`만 바이트 패치 (CRC32 재계산)
- **자르기 렌더링:** `getCropRect(frame)` 헬퍼가 free/locked 모드 모두 처리
  - free: `cropTop/Bottom/Left/Right` (0~1 비율)
  - locked: `cropRatio`, `cropCX/CY` (중앙 %), `cropScale` (최대 박스 대비 0~1)
- **캔버스 크기 모드:** locked 모드에선 크롭 결과가 모두 같은 비율이라 스케일해도 왜곡 없음

## 앞으로 할 수 있는 것들 (아이디어)

- 최근 사용 비율 기억 (localStorage)
- 크기 조정(리사이즈) 도구 추가
- 포맷 변환 도구 (일괄 PNG→JPG 등)
- 자르기 도구에도 종횡비 고정 옵션
- 자르기 도구에 일괄 적용 기능 (같은 영역을 여러 이미지에)
